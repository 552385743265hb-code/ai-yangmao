# 公开 Agent 接入

用户已通过 grilling 确认：公开 Skill 与远程只读 MCP，无需 Key，不包含管理员操作或独立 CLI。

- 最新日报固定生成，飞书与 agent 共用条目、顺序和内容。查询不生成、不翻译、不发消息；无当天日报时注明最近一期日期，不提供历史查询。
- 筛选支持关键词、平台、模型、模态、权益类型、领取方式、状态、截止窗口、门槛、估值方法、排序与分页。默认当前可领，未知价值不按零计算。
- 用户条件仅用于本次查询，未提供即未知；会员资格复用会员合同。输出符合、不符合、待确认三个分组，不保存个人档案。
- 结果含公开权益、领取信息、原语言官方摘录、核验时间与网站链接，不包含审批和内部核验记录。
- 官网提供 Agent 接入页、可安装 Skill、服务端能力说明和 MCP 配置。Skill 可通过 HTTP 独立使用，与 MCP 共用服务层。
- 验证真实 MCP 客户端、HTTP 查询、日报与飞书同源、降级状态和公开字段边界。

工程选择：查询默认 10 条、最多 50 条；无会话 Streamable HTTP；最新日报使用单例存储，沿用飞书现有生成调度与日期口径。部署、生产迁移与推送分别报告。
