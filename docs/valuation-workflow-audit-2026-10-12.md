# 美元参考价值工作流审计

核验时间：2026-10-12 UTC（纽约时间 10 月 11 日晚）。本文面向维护者；公众说明仍在站内「参考价值怎么算」，不展示内部规则版本。

## 实际顺序

1. 正常采集、线索复核、官方补证复用 `pipeline/llm.ts`。agent 从原文抽取权益数量、单位、周期、模型和 `valuationFactors`；不直接填写最终美元金额。
2. 抽取阶段预检因子。明确原文或有效价格目录可支持、但遗漏或格式错误时，在原有预算和截止时间内最多自纠一次。错误、截断、缺价均不能伪造成功。
3. Worker 入库入口验证来源正文、哈希、官方归属及因子绑定，再由共享计算器计算。客户端提交的最终估值不能替代服务端计算。结果先进入待审草稿或更新提案。
4. 人工审核前展示金额、公式、模型、假设和价格来源；有旧版的活动同时保留旧版公开数据。自动计算和补证不会代替人工批准。
5. 最终 Gateway 校验 schema、金额与元数据一致性、官方证据、资格、平台准入及活动身份。数字缺依据时禁止批准；直接修改已公开金额也执行估值检查。
6. 审批以版本断言提交。新人工修改或版本竞争返回冲突，不能用旧计算覆盖。美元金额、上限和估值元数据作为一组保护。
7. 公开接口只输出白名单估值信息；金额与元数据不符时不投影为有效估值。前端只以有效金额排行与汇总，未知不视为零；申请上限与保证金额、月度参考成本分开。

## 本轮发现与处理

| 问题 | 影响 | 处理 |
|---|---|---|
| 有美元数字但 `valuation=null` 能通过审核 | 无来源金额可能发布 | 共享 Gateway 阻断；覆盖 legacy / identity 审批及直接公开编辑，含零金额 |
| Identity 已上架记录的直接金额编辑绕过审批函数 | 可删依据并保留数字 | 在该分支增加估值检查，拒绝后数据库不变 |
| 有可用依据但模型未输出因子，预检直接跳过 | 本可计算却落入待核实 | 原文绑定的金额或匹配目录+数量触发已有的一次自纠，不增加预算或循环 |
| 模型混淆免费积分数与付费参考套餐数 | 免费方案被当作零价，或分母错误 | 明确字段职责与目录 factIds；仍由服务端校验 |
| 审核卡片缺少计算详情 | 人工不能方便核对 | 常规卡片与 Identity 审批卡片展示计算依据 |
| 仅改单个金额与原计算元数据矛盾 | 后端拒绝但原因难理解 | 表单提前解释必须金额、公式、来源一起更正；完整修改仍走管理 API |
| 固定 Token 赠额被月度标准用量截断 | 无法自动复现整笔 20M / 500M 估值 | 已补齐独立 token_grant 分支；20M / 500M 全额计算，实际模型必须有原文支持；不得与无限量/月刷新混用 |

## 真实边界

无法取得官方数量、匹配价格或模型时仍可能需要人工判断。`needs_judgment` 是明确提醒而非数字；允许免费权益在金额留空时收录。不能因四个合成案例通过而宣称所有平台都无需人工干预。

已有人工估值不会随规则或新采集自动被覆盖。后台尚无完整的可视化估值编辑器，完整更正须通过已授权管理接口连同公式、来源、输入提交。
