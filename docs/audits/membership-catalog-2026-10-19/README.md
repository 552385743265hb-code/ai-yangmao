## 验收清单

- `coverage.json` 对生产每个厂商都有官方证据和明确结论，不能把未查到、抓取失败当作没有会员。
- 有会员的厂商：收齐官方列出的所有适用产品和档位（包含明确仍有效的存量会员），名称可独立识别厂商与套餐，收费属性、官方 URL、核验时间完整；没有重复或待核实占位项。
- 会员目录的产品绑定实际厂商，不能仅按域名、裸 Pro/Max 等名称猜归属。停用与改名保留确定的迁移关系；无法唯一定位旧用户选择时保留原选择的待确认提示，不能擅自赋予新会员。
- 录入界面只选厂商、勾选套餐；勾选保存到标准结构，现有已批准条件的迁移不改变实际领取资格。
- 「我的条件」覆盖所有厂商，选择、取消、刷新持久化均通过；同一套餐不能重复添加，厂商缺少订阅时明确展示官方核对结论。
- 审核、快速上架、个人匹配、公开门槛显示使用同一目录；保留必需的真实资格事实。
- 类型检查、完整测试、前端构建通过；针对生产完整目录逐厂商、逐套餐测试 UI 和匹配；线上实测通过。
- 推送、PR 合并、部署、生产数据与版本分别读回验证。
