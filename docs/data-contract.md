# 羊毛数据规格（流水线 × 栏目对照）

字段合同自 2026-10-01 起生效；现役口径校对至 2026-10-09。目标：**一条羊毛审一次，网站所有栏目、统计和推送都一次性正确**，不再事后返工补字段。

代码里的唯一来源：`src/shared/spec.ts`（字段检查、栏目清单、标签词表）。服务器审核、审批卡片“上架前检查”、采集抽取都用它。改规格时先改那里，再同步本文。

## 一、流水线

```
信源抓取 → 关键词筛选 → 模型抽取（全部字段）→ 规整（不合规的值修正为合法值，不丢整条）
  → 入库（待审）→ 媒体稿自动搜索官方补证 → 审批卡片“上架前检查”
      ├─ 通过：进入下表列出的全部栏目
      └─ 拒绝：只进入“准确率”统计和模型学习，不出现在任何公开栏目
```

- **拦截（必须补）**：缺了会让某个栏目算错或显示错，审批时“通过”按钮不可用，服务器也会拒绝。
- **提醒（建议补）**：能通过，但列出的栏目会少数据。检查清单写明影响哪些栏目。
- **可选**：缺了只是显示“官方未写明”或通用文案。
- **已上架的条目**也按同一规格检查，缺字段的出现在审批页“已上架、字段待补”，可以直接补。

## 二、字段 → 栏目

| 字段 | 级别 | 用在哪里 |
|---|---|---|
| 平台 platformId | 拦截（平台须已准入、证据须是该平台官方出处） | 所有栏目；平台页、谁最大方、大方榜、时间线的行、桑基图（平台类型） |
| 标题 title | 拦截（空）/ 提醒（整句英文） | 所有卡片和列表、详情页、墓场、时间线、推送 |
| 类型 type | 拦截（须与截止方式配套） | 今天（限时）/ 常驻额度库 / 申请制 的划分，配色，桑基图，新增类型构成，状态规则 |
| 额度 valueText | 拦截（空）/ 提醒（整句英文） | 详情页、推送；没有美元时卡片上直接显示 |
| 门槛 requirements | 拦截（待确认） | 我的条件筛选、全部羊毛门槛筛选、薅度分“门槛低”“国内直领”、四象限横轴、桑基图、推送 |
| 折合美元 usdEstimate（+ 上限 usdMax） | 提醒 | 今天总价值和羊群大小、日历“当天总价值”、谁最大方、大方榜、常驻额度排行和矩阵、申请制额度图、四象限纵轴、薅度分“价值”、我的本月进度 |
| 领取开始 claimStart | 拦截（已结束的限时活动）/ 提醒（其他限时活动） | 日历（每天有效）、时间线、即将开始、羊毛墓场存活天数、平台发放历史、每周新增和大方榜（按活动开始的日子）、节日往年发过 |
| 领取截止 claimEnd + 截止方式 endKind | 提醒（限时活动截止未知） | 状态（进行中 / 即将结束 / 已结束）、倒计时、3 天内结束、加急推送、日历结束点、时间线、墓场、每周结束数 |
| 官方时区 sourceTz | 必填（默认 UTC） | 所有日期换算成访问者本地时间和北京时间 |
| 免费模型 models | 提醒（免费类条目点名了模型却没填） | 按模型找 |
| 标签 tags | — | 重置时钟（额度重置）；以后的邀请、折扣、每日刷新筛选 |
| 官方发布时间 publishedAt | 提醒（额度重置） | 重置时钟（星期 × 时段分布）、详情页时间轴；没有开始日期时作为“活动出现的日子” |
| 模态 modalities（文本·编程 / 图像 / 视频 / 音频；文本和编程不区分） | 必填 | 今天“按模态分”、常驻额度矩阵、全部羊毛模态筛选 |
| 领取方式 claimMethod | 必填 | 详情页、全部羊毛筛选、桑基图、薅度分“好领取”、推送 |
| 适用对象 audience | 提醒（未写明） | 详情页、推送 |
| 额度有效期 creditValidity | 可选 | 详情页、推送 |
| 领取步骤 steps | 可选 | 详情页、推送（没有时按领取方式显示通用步骤） |
| 官方证据 evidence（链接、级别、原文摘录） | 拦截（媒体转述不能上架，检查清单同样显示为拦截；管理员实测可以）/ 提醒（缺权益原文） | 详情页“官方证据”、薅度分“信源可信”、推送“官方原文”“信源” |
| 牧场心得 adminNote | 可选 | 详情页、推送 |
| 核验记录 reviewMemo | 仅管理员 | 审批卡片；公开接口不输出 |

系统字段（不用审核时填）：发现时间 discoveredAt（详情页“系统发现”）、最近核验 lastVerifiedAt / verifyResult（待核验状态）、官方撤回 withdrawnAt / withdrawnReason（结束、墓场）、首个渠道 firstChannel 和来源信源 sourceId（准确率统计、自动上架）。

**公开文案与内部审核分开（2026-10-09）**：`title`、`valueText`、`steps`、`creditValidity`面向领取福利的用户，只写权益、领取操作、实际资格、用量、费用及期限。核验经过、来源缺口、旧记录误归/误估、重复判定、审批待办、估值取舍写入`reviewMemo`或审核理由，不写入公开简介、步骤或公开的`adminNote`。未知资格/金额仍保留未知字段及证据门槛，不能借清理文案把未证实线索变成确定承诺。入口不可用、领取已结束、绑卡、地区限制与自动续费是用户需要知道的事实，应保留。历史人工纠错及完整修订记录仅通过管理员接口读取。

## 四、统一口径

- **活动出现的日子**：官方开始日期 → 官方发布时间 → 系统发现时间，取第一个有的。“新增”类统计（本周新增、每周新增、大方榜）都按它算，补录的历史活动不会算成本周新增。
- **自动核验与人工复核**：`REVIEW_FIELDS` 声明可比较的业务字段，但先由入库路径保护已审核内容，再比较差异。已上架条目的标题、模态、时区、领取方式、适用对象、步骤、有效期、信源 ID 保留旧值；已有发布时间也保留。额度文字里的数字集合未变时保留旧文案。人工修改过的字段保留；唯一代码例外为官方权益/资格/有效期摘录有非空变化且额度数字也变化时，`valueText` 可进入提案，仍不得直接覆盖。已知日期、美元等抽取缺失时不清空。未被上述规则保护的必要业务字段有实际差异才生成提案，自动上架信源也不能跳过现有条目的复核。
- **比对边界**：字符串统一全半角与空白，数组按集合比较；这不是语义判断。同样数字但不同含义的额度文案、人工锁定字段的真实变化，可能需管理员主动核实并编辑，不能宣传为“所有实际条款变化都会自动发现”。仅证据摘录、页面哈希和抓取时间变化不生成审批任务。
- **核验故障**：页面打不开、原文匹配失败、核验时间过期进入健康监控和自动重试，不进入人工审批队列或每日人工核验提醒；未核验成功期间仍按下述规则显示待核验，不凭抓取失败自动判定结束。
- **状态**：`src/shared/lifecycle.ts` 的 `liveStatus` 是唯一规则，网站 `statusOf` 与之一致。限时活动 48 小时没有复核成功变“待核验”；**管理员实测**的条目没有可自动复核的页面：有截止日期的到截止前一直有效，没有截止日期的 7 天未复测变为待核验，可主动在后台复测，但不自动产生每日人工任务。
- **价值**：折合美元按官方单价保守折算（见通用规则的美元折算口径）；有范围时 usdEstimate 存下限、usdMax 存上限，排序和图表用下限。

- **校验与竞争**：publishedAt只接受合法日精度或带时区ISO；编辑其他字段保留原精度。人工批准记录当次核验时间，仍不绕过evidence_missing或media。核验与提案写入检查读取时版本；普通verify必须显式可信直抓，间接正文不刷新已审核证据。
- **社区补证**：媒体级草稿和更新提案可由固定工作流寻找发放方原文，校验身份、同活动及连续摘录后补字段，仍保持待审。内部official_review不公开、不覆盖memo；sameOccurrenceAs与officialReviewJobId仅为传输控制。队列、重试及恢复统一见[自动官方复核](official-review-workflow.md)。

## 五、通过与拒绝

- **通过**：进入第三节列出的全部栏目；之后的条款变化会生成修订记录，人工改过的字段不会被采集覆盖。
- **已结束但属实**：补全开始和截止日期后**通过**，作为历史数据进入时间线、日历、羊毛墓场、重置时钟、节日往年记录。拒绝理由“旧活动 · 日期查不到”只用于日期实在无法确认的条目。
- **拒绝**：只进入“准确率”统计（拒绝理由、首个渠道）和模型的纠正学习，不出现在任何公开栏目，也不推送。

## 六、现役收录与审核口径

权威业务规则见 [已确认抽取规则](../pipeline/learned-rules.md)，平台特例见 [平台要点](../pipeline/platform-notes.md)。本节给审核者快速决策入口：

- 收实际可量化的 AI Token、积分、次数、API 额度、额外重置/限时加赠，以及身份认证专享的 AI 会员或五折及以下优惠。认证后按月给固定额度用 `standing`，送会员一段时间用 `gift`，有统一活动截止用 `free`；要交材料且人工审核的最高可申请资助才用 `apply`。
- 免费套餐本身的“有限聊天/搜索”、付费套餐内含额度、Relax/Explore、不限量功能、常设阶梯赠送或多送比例不收。2026-09-30 的“超值订阅例外”已被后续规则撤销；OpenCode Go 等不能因额度高于售价就收录。
- 套餐表按月分档的“基础 + 加赠”“每月实得”不因标了“限时”就变成独立福利；须核实套餐之外的活动条件或赠送机制。WorkBuddy 三档月度加赠按套餐自带排除。缺截止日期不是活动不存在的证据，积分有效期不是活动截止。
- Free Tier 与 Free plan/Paid plan 是不同维度；无需先付款的按量计费授权不标 pay，但正文仍注明账户模式及超额收费。一次性注册礼、月度参考素材配额、模型使用扣费分别表述。创业计划的原厂赠金/会员与第三方优惠分别估值，月份精度不补造具体日。
- 普通折扣与首月优惠不收，首月实付不超过 $1 的近免费体验例外保留。网盘等非 AI 会员、通用云数据库/API 网关试用不收。额外奖励只估赠送，不把本金或整个付费档计为免费价值。
- 号池、共享账号、逆向 API、cookie/session 转售及来源不明中转赠额排除；聚合资讯只产线索。正式证据须为实际发放方，合作方宣传不能代替。`media` 在共享检查与服务器审核中均拦截；`tested` 只在管理员明确确认实测时人工设置。
- 摘录保持原语言，来自同一证据页的连续原文。美元优先同平台官方加购价，未有加购价则用同平台套餐中的最低单位费率；无依据留空，不跨平台估计。输入、输出都为零价才算免费模型；模型数量变化的目录不重复造福利条目。
- 国内手机号/支付条件写正文与步骤；`phone/card/net` 表示海外门槛，不能机械套在国内微信手机号授权上。`unknown` 仍是上架拦截。
- 一篇公告多个模型同一种优惠合一条。入库在同一平台内，以“标题数字相同且文本相似度 ≥ 0.85”，或“规范化证据 URL 相同、额度数字相同且额度文本相似度 ≥ 0.85”执行硬性去重；类型和领取方式不参与判定；reset 事件的发放日期不同则不得合并；同日不同出处、未给出 sameAs 同活动判断的候选保留待审并提示核对，不能仅凭同日同名抹掉第二次发放；明确开始日优先于发帖日，明显复用旧日期时由原帖日期保护；独立开始日且出处不同的活动不合并。URL 仅移除跟踪参数，保留活动/文章标识参数，twitter.com/x.com同帖按相同来源比较（见 `src/shared/dedupe.ts`），不能依赖模型 `sameAs` 一项。官方补全和上架阶段另查精确重复（含类型、领取方式、日期等身份字段），冲突保留给管理员合并。
- 新待审按发现时间从早到晚，ID 作并列排序；更新提案接在新条目之后、按更新时间倒序。审批卡片的 `approve/history/reject/judge` 是建议，不改变审核状态，也不代替管理员批准。
- `reject` 拒绝新条目；对已有公开条目存在提案时只处理提案，不等于下架。`unpublish` 撤下误收条目、设为 rejected 并保留历史；`withdraw` 标官方已撤回、进入 ended，两者含义不同。
- 比赛、竞赛、黑客松及排名/投票的获奖奖励不收；同页独立的无需获奖赠额或科研/教学/创业资助按各自条款核验，不连带排除。明确独立资助的可疑空结果须复查或保留待处理。
- 脚本或批量预审只在用户授权范围写字段/内部记录/建议。用户说“不自动通过”时不运行 approve 或带 `--approve` 的编辑。平台准入授权与活动上架授权分开。
