## 各类羊毛的路径检查

| 情况 | 预期路径 / 防错点 |
|---|---|
| 注册赠额、应用尝鲜、每日登录/按月额度 | 新人礼、trial、standing 分开；领取窗口与到账后有效期分别存。Vidu注册礼不能变成每日积分；人工拒绝不能被同一FAQ复活 |
| 订阅套餐、额外福利、充值、折扣 | 套餐内基础/加赠定价不收；独立额外活动才进入审核。首月普通折扣不收，近免费和身份认证大幅优惠按既有例外；账单Paid模式不等于先充值 |
| 学生/教师/设备认证 | 自动身份认证不是人工申请制；赠会员期间与整个项目截止分别处理 |
| 科研/创业资助、比赛获奖 | 申请制资助可收；比赛获奖不收。同页存在两种机制时不连带抹掉可收资助 |
| 一次重置、同日多次、未来多日安排 | 实际发放日与公告时刻分开；明确区间保留；传播回复不是第二次发放，身份不明留待审 |
| 优惠码、邀请、定向资格、多档位/多模型 | 发放方原文支持具体活动；不能用通用兑换教程代替具体码。独立领取渠道可拆，单活动多档位保留美元区间，多模型合并 |
| 已结束活动、未知截止、官方撤回 | 属实的历史保留；未知截止不猜结束；访问失败不当作活动撤回；tested 仅由管理员确认 |
| 未准入平台、管理员锁定字段、社区无可抽取条目 | 留在可见人工处理或待审，不能自动准入、绕过字段保护或批准。补平台/材料后需用现有重试入口；本轮没有替管理员处理这些事实判断 |
