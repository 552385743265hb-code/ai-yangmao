# 已确认的抽取规则

当前收录口径，整理于 2026-10-08。管理员明确确认的纠正直接维护于此；每周自动归纳只提出 PR，须批准后合并。采集管线会把下面以 `- ` 开头的每一行加进抽取提示词。
字段合同与审核操作见 `docs/data-contract.md`。历史提交保留规则演变，本文件不保留已被后续决策撤销的指令。

- 公开文案只面向领取福利的用户：title、valueText、steps、creditValidity只写权益、操作、实际资格、费用及期限；核验过程、来源缺口、历史误归/误估、重复判定、审批待办及估值取舍放reviewMemo或审核理由，不放公开简介、步骤或adminNote。平台要点和管理员纠正只作判断依据，不能抄入公开字段。未知金额/资格保留空值/unknown及原证据门槛，不把未证实线索润色成确定承诺；入口不可用、地区限制、绑卡和自动续费等用户限制须保留。（2026-10-09 管理员纠正TokenRhythm及全站同类文案）

- "首次升级 / 首次付费才赠送"的额度归为 topup（充值赠送），门槛写 pay:首次升级付费套餐；适用对象按原文，只要求"首次升级"时用 all，不要写成 new。
- 一次活动被多个帖子或报道转述时，只收一条；社区帖子里的口语（如"臭鸡蛋也是鸡蛋"）不能当作额度，额度以官方或正式报道的数字为准。
- 平台归真正发放权益的一方：A 公司宣传 B 平台的活动（如 OpenAI 新闻写 Replit 的 Free Mode、腾讯混元推文写 GMI Cloud 的免费试用），platformId 是 B，不是 A。A 的新闻稿只算线索，不能当官方证据；条款（门槛、名额、截止、是否需要付费订阅）必须以 B 自己的官网、博客、价格页或帮助文档为准，officialUrl 填 B 的页面。合作方宣传常省略关键条件，拿不到 B 的原文时 requirements 用 unknown，不要照搬 A 的说法写成零门槛。（2026-09-30 管理员直接要求）
- 额度必须能折合美元横向比较：credits、Neurons、Token、次数等平台自有单位，要找同一平台官方公布的单价（价格页、加购价、按量价）折算成美元写进 usdEstimate，并在 valueText 里注明折算依据；不要只写平台自有单位。（2026-09-30 管理员直接要求）
- 美元折算一律偏保守（2026-09-30 管理员决定）：Token 按官方输入价；只限速率的免费模型按主力模型的官方输入价 × 官方速率上限推出的每月最多 Token（每天最多 Token = min（每天请求数 × 单次最多 Token，每分钟 Token 数 × 1440），× 30）；官方没公开速率上限就留空，不要假设次数或每次 Token 数（2026-09-30 管理员纠正）；各模型独立额度的按官方价格页逐个模型加总，去掉快照版本和语音、同传类作为下限，全部模型作为上限；重置卡按官方全部套餐档位分别折算并列出，下限用最低档。付费套餐内含额度不收录，不能用整个订阅价充当赠额价值。区间用 usdEstimate（下限）和 usdMax（上限）。
- 额度的使用范围必须写清楚：同一平台不同额度可能分别限于模型推理或通用算力，valueText 写明能用在哪些服务、不能用在哪些；范围较窄时标题也注明（如“仅限 Inference Providers”）。不把旧价目示例当现行免费承诺，具体数值以平台要点和当前官方页面为准。
- 条目内容一律用中文：除 excerpts（官方证据原文）外，标题、额度、有效期、领取步骤都写中文；产品名、模型名、计量单位、按钮名、命令等必要英文保留。（2026-09-30 管理员要求）
- 看清模型是什么类型、免费的是哪一部分：价格表里的模型要按官方分类写明是文本、图像、视频还是音频模型；“输入素材价格”（如生成视频时输入音频免费、参考图 N 张以内免费）是每次调用的计费规则，不是“图像生成免费额度”，也不是“首次”赠送；这类只是定价的免费部分，valueText 要写明输出照常收费。（2026-10-01 管理员纠正 MiniMax H3）
- 已经结束的活动也要输出（会作为历史数据进入时间线、日历和羊毛墓场），但必须按官方原文写准 claimStart 和 claimEnd：博客、新闻、更新日志里的活动要看发布日期，开始和结束日期写清楚，不能把旧活动写成现行的或“截止未知”；找不到结束日期时不猜日期；公开文案注明历史活动与当前适用规则，核验缺口放内部记录。（2026-10-01 管理员要求：过期活动不要只拒掉，要进历史）
- 每条福利都要在 models 里逐个列出能免费用的具体模型（官方写法），供“按模型找”汇总某个模型在哪些平台免费；付费套餐里“包含哪些模型”不算免费，不要填。（2026-10-01 管理员要求）

- 充值或付费订阅的“额外赠送”只计算赠送部分：本金/套餐内正常付费额度不能再次记成免费价值，credits 也不能当作模型个数；中文、英文同档不同币种可能重复，重复判断写内部核验记录供管理员处理。（2026-10-01 待审全字段核验）

- 个人激活后的 1/3/7/14/365 天、首次使用后 N 个月是领取后有效期，不是全局领取截止；帮助页更新日期、网站响应时间、旧博客列表日期也不能当活动开始。官方没公布日期就留空，缺口写内部核验记录。（2026-10-01 待审全字段核验）

- 完整免费模型清单必须枚举官方目录全部分页并按免费档/零价版本筛选；支持输入图像或视频不等于可免费生成图像或视频，付费套餐的模型导航与免费可用名单不能混用。（2026-10-01 待审全字段核验）

- 输出字段遵守共享校验：requirements 的 card/biz/phone/net/realname/student/invite/targeted 只能用裸枚举，详细条件写入额度和步骤；只有 pay: 和 member: 可附说明。valueText 不超过 200 字，领取起止是 YYYY-MM-DD，发布时间才能填 ISO 时刻。（2026-10-01 待审全字段核验）

- 号池、自建Pro/Plus账号池、共享订阅账号、逆向接口/转发、cookie或session转售，以及未经授权的来源不明中转站活动一律不输出为羊毛；第三方中转商赠额不能归到OpenAI、Anthropic、Google等原厂。社区宣传“官方接口”不等于授权证明。只有能追到正规发放方官网/正式条款的权益才可进入待审。（2026-10-01 管理员明确要求）
- 学生、教师认证的福利不是申请制：认证通过就自动拿到固定额度。按送的东西定类型——送付费会员一段时间是 gift，认证后按月给额度是 standing（个人有效期如“认证后 12 个月”写进额度有效期，不是活动截止），整个计划有截止日期才是 free；门槛写 student（教师也用 student，额度里写明教师认证）。只有要交材料、人工审批、额度为“最高可申请”的科研/创业资助才是 apply。（2026-10-01 管理员确认）
- 会员档位本身包含的权益（每档每月积分、可用模型、无限量、特权）不是羊毛，按“付费套餐自带”拒绝；可收的是免费档里可量化的 AI 额度、订阅档额外的额度重置、常规套餐之外的加赠（重置卡、多送的 Token、限时翻倍）。（2026-10-02 管理员确认，清理 31 条档位条目）

- 同一价格页须逐项判断，排除付费套餐不等于丢弃整页：WorkBuddy 免费体验版每月 500 基础积分仍可收。需审核获批的创业资助用 apply，长期开放只决定 endKind=standing；免费赠送含 AI 使用的会员时长可收，席位数量只是上限，不与普通协作席位混淆。模态按实际服务，参考图/多模输入不代表免费生成图像；Vidu Q4视频积分只填video，Claude第一方API/Team创业权益只填text。（2026-10-08 真实模型回归纠正）
