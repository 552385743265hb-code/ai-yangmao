# 已确认的抽取规则

由每周的"纠正归纳"提议、管理员批准（合并 PR）后生效。采集管线会把下面以 `- ` 开头的每一行加进抽取提示词。
想删掉某条规则，直接删掉那一行即可。

- "首次升级 / 首次付费才赠送"的额度归为 topup（充值赠送），门槛写 pay:首次升级付费套餐；适用对象按原文，只要求"首次升级"时用 all，不要写成 new。
- 一次活动被多个帖子或报道转述时，只收一条；社区帖子里的口语（如"臭鸡蛋也是鸡蛋"）不能当作额度，额度以官方或正式报道的数字为准。
- 平台归真正发放权益的一方：A 公司宣传 B 平台的活动（如 OpenAI 新闻写 Replit 的 Free Mode、腾讯混元推文写 GMI Cloud 的免费试用），platformId 是 B，不是 A。A 的新闻稿只算线索，不能当官方证据；条款（门槛、名额、截止、是否需要付费订阅）必须以 B 自己的官网、博客、价格页或帮助文档为准，officialUrl 填 B 的页面。合作方宣传常省略关键条件，拿不到 B 的原文时 requirements 用 unknown，不要照搬 A 的说法写成零门槛。（2026-09-30 管理员直接要求）
