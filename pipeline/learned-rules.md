# 已确认的抽取规则

当前收录口径，整理于 2026-10-07。管理员明确确认的纠正直接维护于此；每周自动归纳只提出 PR，须批准后合并。采集管线会把下面以 `- ` 开头的每一行加进抽取提示词。
字段合同与审核操作见 `docs/data-contract.md`。历史提交保留规则演变，本文件不保留已被后续决策撤销的指令。

- "首次升级 / 首次付费才赠送"的额度归为 topup（充值赠送），门槛写 pay:首次升级付费套餐；适用对象按原文，只要求"首次升级"时用 all，不要写成 new。
- 一次活动被多个帖子或报道转述时，只收一条；社区帖子里的口语（如"臭鸡蛋也是鸡蛋"）不能当作额度，额度以官方或正式报道的数字为准。
- 平台归真正发放权益的一方：A 公司宣传 B 平台的活动（如 OpenAI 新闻写 Replit 的 Free Mode、腾讯混元推文写 GMI Cloud 的免费试用），platformId 是 B，不是 A。A 的新闻稿只算线索，不能当官方证据；条款（门槛、名额、截止、是否需要付费订阅）必须以 B 自己的官网、博客、价格页或帮助文档为准，officialUrl 填 B 的页面。合作方宣传常省略关键条件，拿不到 B 的原文时 requirements 用 unknown，不要照搬 A 的说法写成零门槛。（2026-09-30 管理员直接要求）
- 额度必须能折合美元横向比较：credits、Neurons、Token、次数等平台自有单位，要找同一平台官方公布的单价（价格页、加购价、按量价）折算成美元写进 usdEstimate，并在 valueText 里注明折算依据；不要只写平台自有单位。（2026-09-30 管理员直接要求）
- 美元折算一律偏保守（2026-09-30 管理员决定）：Token 按官方输入价；只限速率的免费模型按主力模型的官方输入价 × 官方速率上限推出的每月最多 Token（每天最多 Token = min（每天请求数 × 单次最多 Token，每分钟 Token 数 × 1440），× 30）；官方没公开速率上限就留空，不要假设次数或每次 Token 数（2026-09-30 管理员纠正）；各模型独立额度的按官方价格页逐个模型加总，去掉快照版本和语音、同传类作为下限，全部模型作为上限；重置卡按官方全部套餐档位分别折算并列出，下限用最低档。付费套餐内含额度不收录，不能用整个订阅价充当赠额价值。区间用 usdEstimate（下限）和 usdMax（上限）。
- 额度的使用范围必须写清楚：同一平台不同身份的额度能用在哪里常常不同（如 Hugging Face 免费用户 $0.10 只能用于 Inference Providers，PRO 的 $2 可用于全部算力服务），valueText 要写明能用在哪些服务、不能用在哪些，范围较窄时标题里也要注明（如“仅限 Inference Providers”）。（2026-09-30 管理员要求）
- 条目内容一律用中文：除 excerpts（官方证据原文）外，标题、额度、有效期、领取步骤都写中文；产品名、模型名、计量单位、按钮名、命令等必要英文保留。（2026-09-30 管理员要求）
- 看清模型是什么类型、免费的是哪一部分：价格表里的模型要按官方分类写明是文本、图像、视频还是音频模型；“输入素材价格”（如生成视频时输入音频免费、参考图 N 张以内免费）是每次调用的计费规则，不是“图像生成免费额度”，也不是“首次”赠送；这类只是定价的免费部分，valueText 要写明输出照常收费。（2026-10-01 管理员纠正 MiniMax H3）
- 已经结束的活动也要输出（会作为历史数据进入时间线、日历和羊毛墓场），但必须按官方原文写准 claimStart 和 claimEnd：博客、新闻、更新日志里的活动要看发布日期，开始和结束日期写清楚，不能把旧活动写成现行的或“截止未知”；找不到结束日期时，在 valueText 里写明“发布于某日，是否仍有效需核实”。（2026-10-01 管理员要求：过期活动不要只拒掉，要进历史）
- 每条福利都要在 models 里逐个列出能免费用的具体模型（官方写法），供“按模型找”汇总某个模型在哪些平台免费；付费套餐里“包含哪些模型”不算免费，不要填。（2026-10-01 管理员要求）

- 充值或付费订阅的“额外赠送”只计算赠送部分：本金/套餐内正常付费额度不能再次记成免费价值，credits 也不能当作模型个数；中文、英文同档不同币种可能是重复条目，先写明供管理员判断。（2026-10-01 待审全字段核验）

- 个人激活后的 1/3/7/14/365 天、首次使用后 N 个月是领取后有效期，不是全局领取截止；帮助页更新日期、网站响应时间、旧博客列表日期也不能当活动开始。官方没公布日期就留空并写明缺口。（2026-10-01 待审全字段核验）

- 完整免费模型清单必须枚举官方目录全部分页并按免费档/零价版本筛选；支持输入图像或视频不等于可免费生成图像或视频，付费套餐的模型导航与免费可用名单不能混用。（2026-10-01 待审全字段核验）

- 输出字段遵守共享校验：requirements 的 card/biz/phone/net/realname/student/invite/targeted 只能用裸枚举，详细条件写入额度和步骤；只有 pay: 和 member: 可附说明。valueText 不超过 200 字，领取起止是 YYYY-MM-DD，发布时间才能填 ISO 时刻。（2026-10-01 待审全字段核验）

- 号池、自建Pro/Plus账号池、共享订阅账号、逆向接口/转发、cookie或session转售，以及未经授权的来源不明中转站活动一律不输出为羊毛；第三方中转商赠额不能归到OpenAI、Anthropic、Google等原厂。社区宣传“官方接口”不等于授权证明。只有能追到正规发放方官网/正式条款的权益才可进入待审。（2026-10-01 管理员明确要求）
- 学生、教师认证的福利不是申请制：认证通过就自动拿到固定额度。按送的东西定类型——送付费会员一段时间是 gift，认证后按月给额度是 standing（个人有效期如“认证后 12 个月”写进额度有效期，不是活动截止），整个计划有截止日期才是 free；门槛写 student（教师也用 student，额度里写明教师认证）。只有要交材料、人工审批、额度为“最高可申请”的科研/创业资助才是 apply。（2026-10-01 管理员确认）
- 会员档位本身包含的权益（每档每月积分、可用模型、无限量、特权）不是羊毛，按“付费套餐自带”拒绝；可收的是免费档里可量化的 AI 额度、订阅档额外的额度重置、常规套餐之外的加赠（重置卡、多送的 Token、限时翻倍）。（2026-10-02 管理员确认，清理 31 条档位条目）
- 非 AI 额度的会员权益（网盘、视频、音乐等会员天数）不是 AI 羊毛，即使是 AI 产品送的也按 not_ai 拒绝；只收 AI 模型额度、Token、积分或 AI 产品本身的会员。（2026-10-02 百度库库送网盘会员）
- 免费档每月 0 额度、只能另购积分包（如 Pika“Free 0 credits / month · packs only”）的不是羊毛；“免费版含所有模型 / 无水印”这类功能说明不等于有免费额度，必须有实际可用的积分、次数或 Token 才收。（2026-10-03 管理员实测 Pika 免费版无法生成）
- 价格表（模型 | 输入 | 输出）逐行对齐模型名和价格，不能把相邻行的“Free”“$0.00”套到别的模型；只有输入和输出都为 $0 的才算免费模型，只有输出免费的不算。（2026-10-03 Together AI 把上一行 Tev1 4B 的 $0.04 Free 误套到 Gemma 4 31B）
- 产品“基础模式不扣积分”（如 WPS 灵犀快速模式）、“自带 API Key 时平台工具暂不扣费”（如灵犀自定义模型下的搜索 / 生图）这类附加条件多、没有可量化额度的，不收。“限时免费”的提示先读完整段话，看清前提条件。（2026-10-03 管理员判断）
- 没有官方单价时不能“参考其他平台平均积分价值”编美元；用同平台官方套餐价 ÷ 套餐所含积分算出的费率保守折算，并在额度里写明依据，连套餐价都没有就留空。（2026-10-03 千问办公三条美元均为编造）
- 证据原文摘录必须保留原语言逐字摘录，不能机器翻译（Free.ai 资格被译成“融资低于 5 亿美元”，原文是 $5M）；翻译只放在额度和步骤里。（2026-10-03）
- 积分包、充值包价目表上“买得越多送得越多”（如 Tripo $100 送 2,000、$1,000 送 30,000）是常设的阶梯价 / 批量折扣，任何时候买都有，属于营销话术，不收，也不要按档位拆条；只有限时活动里写明额外加赠的才收。（2026-10-03 管理员确认）
- 首月优惠（首月几折、新用户首月半价等）不收，很常见、不是免费额度；例外：首月实付不超过 $1（约 ¥7）、基本等于免费的保留（如 ElevenLabs Starter 首月 $1），打 discount 标签。（2026-10-03 管理员决定）
- 普通年付相对月付的折扣、年付“相当于免 N 个月”都是订阅定价，不收，即使优惠达到五折也不例外（如 Tripo 年付 50%、MiMo 年付 12%）；五折及以下的优惠例外仅针对身份认证专享，不适用于一般年付、首购或 API 单价打折。先读完整条款：若确实另发套餐之外的积分或 Token（如 Runway 企业签约后的独立 bonus credits），只核额外赠送部分，不能仅凭宣传中的“免费 N 个月”通过或拒绝。（2026-10-07 管理员要求清理同类条目）
- 证据级别 tested（管理员实测）只能在管理员亲口确认实测过时使用；批量核验或模型不能自己标 tested，也不能引用仓库里不存在的截图。（2026-10-03 Suno 邀请条目被错标 tested）
- 官方摘录必须来自证据URL同一页、保留原语言且是一段连续原文，不翻译、不拼接表格多行、不伪造截图。当前verify实现把连续空白折为单空格并忽略大小写后包含匹配，不是完全删除所有空白；抓取页未呈现的脚本卡片优先改用可读FAQ。必要字段已重新抽取且与已审核版本相同、页面哈希对应且无提案时，代码也允许自动核验成功。
- 证据页要和摘录同一页：同一平台不同页面（如 ElevenLabs v4 页和 pricing 页）内容不同，摘录只能取自证据链接那一页。
- reset 标签只用于订阅额度的重置事件；每月固定的免费次数、每月发放的积分不打 reset。（2026-10-03）
- 云厂商的通用产品试用（数据库、容器、BI、云服务器、直播点播、API 网关、消息通道）不是 AI 额度，按 not_ai 不收；只收模型推理、AI 服务（语音、翻译、OCR 等）的免费额度。（2026-10-03）
- 付费档里的 Relax / Explore / 慢速无限量模式、年付档全年不限量模型，都是档位自带权益，按 paid_bundle 不收；价目表上常设的“订阅多送 X%”（如 $20 得 $22）同样不收。（2026-10-03）
- 多个付费档的积分折美元：取各档“套餐价 ÷ 所含积分”里最低的费率（最保守），有官方加量包单价时优先用加量包单价；在额度里写明依据。（2026-10-03）
- 帮助文章、文档页的编辑日期不是活动发布时间，publishedAt 留空；发布时间只取公告、博客、推文的发布时刻。（2026-10-03）
- 已上架条目重新核验时，改动会进入“条款更新提案”，要管理员接受才生效；批量核验的结果里要列出这些条目。（2026-10-03）
- 模型公司和 AI 产品的免费套餐本身（ChatGPT、Claude、Le Chat、Grok、Gemini 等免费版的“有限聊天 / 搜索 / 生图次数”）不是羊毛，是套餐价目里的 Free 档；只有免费档里附带的、可量化的额度才收，如 Mistral 免费计划每月 $10 API credits、AI Studio 免费 API 额度。只写“limited / generous limits”而没有具体额度的免费版不收。（2026-10-03 管理员确认）
- 门槛判断看“要用上这份额度必须做什么”：要先给 API 充值、绑卡才能调用的，写 card + pay，不是零门槛；官方明确写“无需信用卡”的才写 none。（2026-10-03）
- 打折不收有一个例外：学生、教师、特定设备持有人等身份认证专享的免费会员或大幅折扣（五折及以下）算羊毛，如 Google AI Pro 美国大学生免费 12 个月、全球大学生 AI Plus 12 个月、买 Pixel 10/11 Pro 送 AI Pro、Mistral 学生价 $5.99（原 $14.99）、GitHub Copilot 学生计划 / 教师免费 Pro。送会员一段时间写 gift，按月给额度或长期免费写 standing，大幅折扣写 topup + discount 标签；Otter 学生八折这类小折扣仍不收。（2026-10-03 管理员确认）
- 一篇公告里同时宣布多个模型的同一种优惠（如 Windsurf 2026-02-16 GLM-5 0.75x、MiniMax M2.5 0.25x），只收一条，各模型倍率或额度写进额度说明；不要每个模型建一条。（2026-10-03 管理员确认）

- 不同日期的额度重置、重置卡发放是独立活动；不能因同名/同额度而并入历史事件。sameAs 只用于同一次发放的预告、到账确认等转述，入库对 reset 事件按日期作硬性保护。（2026-10-08 新线索到审链路修复）
